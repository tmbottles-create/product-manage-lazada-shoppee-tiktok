Shopee Lazada Product Studio

Quick user manual for daily product, category, export, and path setup work.

1. Start Here

  1. Open Config > Config Path.
  2. Check Database, Template, and Export paths.
  3. Save path settings before importing or exporting.
Tip: If templates are not found, check the Template Path first.

2. Product Menu

  1. Use Product List to view all items.
  2. Use Add Product to create a new item.
  3. Use Copy Product to duplicate a selected item.
  4. Use Search to filter by category or product name.

3. Category Setup

Category Mapping

  • Open Master > Category Mapping.
  • Match Product Category to Lazada Sheet, Shopee Category ID, and TikTok Category.
  • Save after editing mappings.

Category Masters

  • Master > Lazada Cat Master: add, edit, delete, or import Lazada category values.
  • Master > Shopee Cat Master: manage Shopee category ID master values.
  • Master > TikTok Cat Master: add, edit, delete, or import TikTok category values.

4. Export Workflow

  1. Select products in Product List.
  2. Use Export > Export Shopee, Export Lazada, or Export TikTok.
  3. Open the generated file from the workspace buttons if needed.
  4. Check the Export Path if you cannot find the output file.

5. Common Problems

  • If category lists are empty, check Template Path or Category Master data.
  • If export fails, confirm Category Mapping is saved first.
  • If the app reads the wrong folder, update it in Config > Config Path.
